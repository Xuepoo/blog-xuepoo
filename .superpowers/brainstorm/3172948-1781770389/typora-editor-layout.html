2. 核心技术升级点

✨ 新增特性

  • Frontmatter 一体化编辑：去除顶部输入表单，完全还原本地编写 Markdown 文章的纯粹体验。
  • Ctrl+V 剪贴板图片直传：监听 `paste` 事件拦截图片文件，自动发起 `POST /api/images` 接口转换上传，并在光标处自动插入标准的 Markdown 图像引用。
  • 侧边栏折叠与三种视口切换：使用本地状态自由开合侧栏；支持“纯源码”、“左右双栏同步对比”、“纯预览”三种模式。
  • 物理文章删除：左上角加入“删除文章”功能，支持弹窗二次确认后通过 `DELETE /api/posts/:filename` 将本地文章在磁盘上安全抹除。

⚠️ 注意事项

  • Zola 前置元数据语法：文章头部必须正确编写 `+++` 前缀和后缀，如果 TOML 语法错误，Zola 将无法正常解析编译。
  • 删除文件不可恢复：磁盘文件删除后将直接移除（非移入垃圾箱），必须通过 Git 撤销修改来进行版本找回。

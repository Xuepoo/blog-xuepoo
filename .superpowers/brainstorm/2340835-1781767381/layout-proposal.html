2. 本地命令行 `Justfile` 核心任务链

我们将使用 Rust 社区流行的任务运行工具 `just` 来提供高内聚的工作流指令，摆脱零散脚本：

1

just edit

启动本地博客开发模式。并联运行 Zola 热重载预览服务器（端口 8085）和轻量级本地 Node.js API 读写服务，并在浏览器自动打开编辑入口。

2

just status

检查本地待发布文件的状态。例如：自动扫描新文章中引用的本地图片，检查它们是否还未转换成 WebP 格式。

3

just deploy

一键安全编译和发布：首先运行代码风格检查，检测并转换文章中的新图片为 WebP，上传图片至 R2，重新渲染替换图片链接为 CDN URL，最后生成 Zola 静态站点并部署至 Cloudflare Pages。

4

just push

本地静态部署成果满意后，一键自动同步 Git 源码。依次执行 `git add`, `git commit` 以及 `git push` 把源码同步至 GitHub 仓库进行备份。
